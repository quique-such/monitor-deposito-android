# App Android — Monitor de depósito

Aplicación Android nativa que monitoriza en tiempo real el estado de un depósito de agua, comunicándose por UDP con un servidor Java. Incluye controles de entrada/salida y visualización de caudales.

**Tecnologías:** Kotlin · Android · UDP
